AgentPlaytest — demo

One tiny game (Snack Stand). One checker. Local open-weight Gemma models, run 100% locally — plus one hosted frontier-model validation below. Two interfaces, two model sizes — the full 2×2 grid, all four cells captured. Same model, same harness; the only thing that changes between the left and right columns is how much the interface explains itself.

✅ Model-friendly interface — Gemma 3 4B

35.0 / 100 (grade D)

Plain state names, the goal stated up front, every action explained. Real play: bought, sold, 2 of 4 milestones — then fixated on re-setting its price.

🚧 Model-hostile interface — Gemma 3 4B

0.0 / 100 (grade F)

The same 4B model that scored 35 on the left. Here it cycled two coded actions into the same E04 error for 20 steps and never moved the progress metric at all.

✅ Model-friendly interface — Gemma 3 1B

0.0 / 100 (grade F)

Even with every explanation the interface can give, the 1B repeated its first action for 60 straight steps. Below a capability floor, the model is the bottleneck.

🚧 Model-hostile interface — Gemma 3 1B

0.0 / 100 (grade F)

Coded keys (d, c, s, p), actions named op_a…op_h, result codes instead of sentences, and the goal never mentioned. It skipped the whole week in 7 steps.

Frontier validation — GPT-OSS 120B (hosted, same checker, no code changes)

Pointed at OpenAI's GPT-OSS 120B through Groq's free tier — just a different --base-url/--model, a disclosed 12-second step pacing for the free tier's rate limits, and a 2,500-token reply budget (reasoning models need room to think; the local Gemma runs used 80). The pair it produced is the experiment in one line: friendly 100.0 (A) — goal reached in 9 steps; hostile 20.6 (F) — the model probed all eight opaque actions systematically, decoded enough to make one sale, then stalled for 7 straight steps. Capability compensates for a hostile interface partially, not fully.

✅ Model-friendly interface — GPT-OSS 120B

100.0 / 100 (grade A)

Goal reached in 9 steps: bought, priced, advertised, sold — all 4 milestones.

🚧 Model-hostile interface — GPT-OSS 120B

20.6 / 100 (grade F)

Same model, same 20-step budget. One sale decoded out of coded feedback (1 of 4 milestones, 14% progress) — then a 7-step no-progress stall.
