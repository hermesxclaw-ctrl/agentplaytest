AgentPlaytest — demo

One tiny game (Snack Stand). One checker. Local open-weight Gemma models, run 100% locally. Two interfaces. Note the two captured reports below use different model sizes — the friendly report is Gemma 3 4B, the hostile report is Gemma 3 1B (the 4B hostile run was not captured; see the project README for the full results grid, including that gap).

✅ Model-friendly interface — Gemma 3 4B

—

Plain state names, the goal stated up front, every action explained.

🚧 Model-hostile interface — Gemma 3 1B

—

Coded keys (d, c, s, p), actions named op_a…op_h, result codes instead of sentences, and the goal never mentioned.

Full transcripts: runs/run-friendly.json and runs/run-hostile.json. Reproduce locally with the commands in the project README.
